# MyAppDemo

一个使用 Kotlin、XML View 与 ViewBinding 开发的 Android 排班日历应用。

## 功能

- 按自定义基准日期和循环周期推算每天班次
- 月历查看、跨月切换和今日高亮
- 标准周排班与 1×4 两种桌面小组件
- 明亮、夜间和跟随系统主题
- 基于 Open-Meteo 的当前天气（无需 API Key）
- App 与桌面小组件同步显示城市、天气图标、温度和天气文字
- 可选特殊天气提醒：约每小时检查未来 3 小时的雷暴、冰雹、冻雨、强降雨和强降雪

## 天气设置

进入“设置”，先选择省级地区，再从联动列表中选择天气城市并保存。城市数据覆盖中国大陆 31 个省级地区以及香港、澳门、台湾，共收录 150 余个省会、区域中心和重点城市。天气成功获取后会按城市缓存；断网时继续显示最近一次成功结果。

天气数据来自 [Open-Meteo](https://open-meteo.com/)。应用不会申请定位权限。

## 特殊天气提醒

在设置页开启“特殊天气提醒”后，应用约每小时获取一次预报，并检查未来 3 小时内的雷暴、冰雹、冻雨、强降雨和强降雪。相同等级事件默认 6 小时内不重复通知，风险升级时可再次通知。Android 13 及以上会在开启该功能时申请通知权限；如果用户拒绝，应用会关闭提醒开关并提供前往系统设置的入口。

## Widget 更新策略

- 下一本地日期零点后使用一次性非精确闹钟刷新排班
- 开机、系统时间或时区变化后恢复调度
- 系统每小时 Widget 更新作为兜底
- 天气由 `JobScheduler` 在联网时周期刷新

该策略不需要“精确闹钟”特殊权限；受 Android Doze 和厂商省电策略影响，跨日刷新可能短暂延迟。

## 构建

```powershell
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

项目最低支持 Android 7.0（API 24）。`java.time` 通过 core library desugaring 支持 API 24–25。
